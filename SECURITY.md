# Security

Hiro Budget runs on your computer only. It has no server, no account and sends no
telemetry. The only network access is the optional bank fetch (FinTS) to your bank's
server, started by you; the PIN is asked for each time and not stored.

Your data (statements, database, configuration) stays in the folders you choose; back them
up like other personal files.

Plugins of your own with program code run with the same rights as the app: only enable
plugins you trust (Settings → Plugins).

**Reporting a vulnerability:** please do not open a public issue. Use GitHub's
"Report a vulnerability" (Security tab of the repository) for a private report.
